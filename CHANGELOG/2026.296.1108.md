# 2026.296.1108 — feat(crabbox): build the CLI from the pinned opencharly/crabbox commit

## Summary

W6's producer leg: `layer-crabbox` stops installing the 0.79.0 release from
`openclaw/crabbox` (which can never carry the `containerd` SSH-lease provider) and
BUILDS the CLI from `opencharly/crabbox` at the pinned merge commit
`b7b5aaa312fdcd0711b4407935ce4d50117e8155` (`opencharly/crabbox#7`, W2 seam 1).

- `crabbox` candy: ONE `command:` step fetches the commit's source tarball
  (curl → extract to a temp dir), runs `go build -trimpath ./cmd/crabbox` with
  `-X .../internal/cli.version=<commit>`, and removes the tree with a `trap` in
  the same RUN — so `crabbox --version` reports the commit it was built from and
  no layer carries the source. New checks assert the provider
  surface the release does not have: `providers` lists `containerd` and
  `providers describe containerd` succeeds. The retired `CRABBOX_VERSION` var and
  the GoReleaser archive install are DELETED (R5).
- `crabbox-containerd-config` candy (separate, referenced by path so the root
  `crabbox` ref keeps its meaning): renders `~/.config/crabbox/config.yaml` with
  `provider: containerd` and `containerd.image`, through the `config:` verb
  against the vendored `crabbox-yaml` schema.
- `box/check-crabbox-cli/`: the R10 witness in a disposable container.
- `layer-golang` is composed for the build (the same recipe
  `layer-agentteams-cli` uses for a pinned Go source build). The compile is bounded
  (`GOMAXPROCS=2`, `GOFLAGS=-p=2`, `GOGC=50`, `-s -w`): an unbounded build and a
  full-size linker exhaust the builder's memory (MEASURED — the buildkit worker
  was OOM-killed twice), and the bounds make the recipe reproducible on a shared
  builder.
- `crabbox doctor` is deliberately NOT an image-build check: it judges a LIVE
  venue's provider prerequisites (a daemon/broker), which a build container does
  not have. The venue's readiness is judged by plugin-crabbox's
  `containerd-preflight` in the e2e bed (R8).

Producer-first: `opencharly/plugin-crabbox` pins this repo's new tag in a
follow-up PR after this merges and tags.

Refs opencharly/plugin-crabbox#15.
